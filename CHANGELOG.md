# Changelog

## 0.1.0

- Colour swatches and VS Code's colour picker for `0xRRGGBB` and `0xRRGGBBAA` literals in any language.
- Alpha slider support; 6-digit values upgrade to 8 digits when alpha is lowered.
- Settings: `enabled`, `alphaPosition` (`end` = RRGGBBAA, `start` = AARRGGBB), `letterCase`, `excludedLanguages`.
- Command: *Color Picker For Code: Pick Color at Cursor*.
